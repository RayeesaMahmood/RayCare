# RayCare — AI-Enabled Hospital Queue Management System

Real-time hospital queue management with emergency booking, live patient tracking, and sub-1-second state sync across concurrent users. Published at the ORCHIDS International Conference.

**Live demo:** https://raycare.vercel.app
**Publication:** https://doi.org/10.6084/m9.figshare.30545999

## What it does

- Real-time queue position tracking so patients and staff see the same live state
- Emergency booking flow with priority handling
- Concurrent multi-user data sync via Firebase Realtime Database (sub-1-second latency)
- Admin dashboard for staff-side queue management

## Tech stack

Firebase Realtime Database · JavaScript · HTML/CSS · Vercel
